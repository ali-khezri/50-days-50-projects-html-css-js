# 50 Projects in 50 Days – HTML, CSS & JavaScript

50 days, 50 frontend projects — practicing HTML, CSS, and JavaScript through small, focused UI components and mini-apps.

Each project lives in its own folder and includes:

- `index.html`
- `style.css`
- `script.js`

The goal was **daily practice**, improving core frontend skills, and keeping consistent commits.

---

## 🚀 Goals

- Strengthen HTML, CSS & JavaScript fundamentals
- Practice DOM manipulation & event handling
- Improve UI/UX thinking
- Build consistency through daily coding
- Create a collection of small projects for my portfolio
